Создай профессиональную интерактивную сравнительную таблицу LED-контроллеров и медиаплееров для сайта. Таблица должна использоваться как инженерный справочник и инструмент подбора оборудования для менеджеров, интеграторов и технических специалистов.

Основные требования:

* Современный минималистичный интерфейс
* Desktop-first, но адаптивный
* Темная и светлая тема
* Быстрая фильтрация и сортировка
* Возможность масштабирования базы моделей
* Архитектура без хардкода UI-компонентов
* Данные должны храниться в JSON / API-структуре
* Каждая характеристика должна иметь tooltip-подсказку как mini-wiki
* Подсказки показываются при hover и tap на мобильных устройствах
* Термины должны иметь пунктирное подчеркивание
* Tooltip должен содержать:

  * краткое определение
  * практическое значение
  * где параметр критичен

Пример:

* FPS → "Частота кадров в секунду. Влияет на плавность отображения видео и совместимость с источниками сигнала."
* HDR → "Расширенный динамический диапазон. Улучшает контраст и детализацию изображения."
* Genlock → "Синхронизация видеосигнала с внешним источником. Используется в broadcast и XR."

# 3. UX детали

* Tooltip открывается плавно
* Tooltip не должен выходить за границы экрана
* На мобильных tooltip открывается по tap
* При hover строка подсвечивается
* Поддержка sticky columns
* Возможность скрывать/показывать колонки
* Цветовая индикация:

  * HDR → зеленый
  * Genlock → фиолетовый
  * Low latency → синий
  * Budget → серый
  * Broadcast → красный
